# Speak B1 — English Speaking Topics 🗣️

**كل الكلمات من ملفاتك، مُرتّبة في مواضيع تقدر تتكلم بيها — لمستوى B1.**
All your vocabulary, reorganized from alphabetical / level-based lists into
**speaking topics** for a B1 learner. Bilingual (English + عربي), searchable,
works on phone and computer, light & dark mode.

---

## 📖 إزاي تستخدمه · How to use

1. افتح ملف **`index.html`** في أي متصفح (موبايل أو كمبيوتر).
   Open **`index.html`** in any browser.
2. اختر موضوعًا من الفهرس وتكلّم عنه دقيقة كاملة مستخدمًا مفرداته وجُمله.
3. جاوب على أسئلة **«Speaking practice»** (الصندوق البرتقالي) بصوتك.
4. استخدم **البحث** بالأعلى لتلاقي أي كلمة (إنجليزي أو عربي).

> اقرأ الكلمات بصوت عالٍ: غطِّ العمود العربي وتذكّر المعنى، ثم العكس.

## 🔧 التعديل والتوليد · Editing & rebuilding

المحتوى كله في **`src/content.py`**، والتصميم في **`src/assets/`**.
لإعادة التوليد بعد أي تعديل:

```bash
cd src
python3 build.py     # يُنشئ index.html و B1_Speaking_Topics.html
```

- `src/content.py` — كل الكلمات والمواضيع والجُمل (عدّل هنا لإضافة كلمات).
- `src/assets/style.css` — الألوان والخطوط والتصميم.
- `src/assets/app.js` — البحث وتبديل الوضع الليلي.
- `src/assets/template.html` — هيكل الصفحة.
