# Clause & Effect

A live conjunctions quiz game for Grade 10.

- **Host a game:** one screen (laptop or projector) hosts and gets a fresh join link, QR code and 4-letter code every game.
- **Join a game:** players open the link on Android or iPhone, build a character and answer on their phones.
- **Play on this device:** 1–4 players take turns on one screen, with optional computer rivals.

Only players who answer correctly earn a power-up pick after each question.

Play it at https://emanelzordok666.github.io/Emanelzordok666/ — it can be installed to a home screen like an app.
